## Bug fixed: overlapping outcomes inflated adaptive confidence

The adaptive tuner used Wilson win-rate bounds as if every resolved journal row were independent. Repeated daily signals for one ticker share most or all of the same five-session forward outcome window. The current journal contains clusters of overlapping `IONQ` and `LUNR` observations, so counting every row could manufacture confidence and trigger autonomous threshold changes too early.

Changes in `scanner/learning/adaptive_policy.py`:

- Adaptive evidence now reuses the edge lab's 11-calendar-day same-ticker embargo before calculating threshold metrics or making any automatic recommendation.
- Evidence with no usable ticker or source/decision date fails closed instead of increasing the sample count.
- Embargoing is performed separately for each score threshold, so a lower-score observation cannot incorrectly suppress a later high-score observation from that threshold's cohort.
- Reports now retain raw counts but expose independent counts, overlap exclusions, and the embargo used.
- Doctrine state summaries and Kronos-lift summaries now use independent outcome windows as well.
- Added regressions proving eight overlapping wins from one ticker count as one independent window, while observations 11 days apart remain distinct.
